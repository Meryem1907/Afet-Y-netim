# Afet ve Acil Durum Yönetim Sistemi

## Proje Amacı
Bu proje, afet bölgelerindeki personel, kaynak ve taleplerin yönetilmesini sağlamak amacıyla geliştirilmiştir.

## Kullanılan OOP Kavramları
- Kalıtım (Inheritance)
- Soyutlama (Abstraction)
- Kapsülleme (Encapsulation)
- Çok Biçimlilik (Polymorphism)
- Arayüz (Interface)

## Sınıflar
- Kisi
- Personel
- Vatandas
- Kaynak
- Talep
- AfetBolgesi
- DosyaYonetici
- KaynakDagitimServisi
- AfetYonetimSistemi
- Main

## Özellikler
- Personel ekleme
- Kaynak ekleme
- Talep ekleme
- Kaynak dağıtımı
- TXT dosyasına kayıt işlemleri
- Rapor görüntüleme

## Çalıştırma
Main.java dosyası çalıştırılarak sistem başlatılır.
